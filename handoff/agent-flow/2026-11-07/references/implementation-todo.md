## 已确认的规则

- 工作节点表示由某个 Agent 角色完成的任务步骤。
- 执行线：推进执行，并交接来源本次执行的结果。
- 输入线：额外引用来源结果，不启动或反向执行来源，不单独启动目标。
- 任务结果：该任务最终说明与产物文件引用，不自动传递它收到的全部输入或完整会话。
- 条件节点：读取来源任务的判断结论，选择一条执行路线，透传对应来源结果。
- all：等待本次有效分支完成，合并这些分支结果；不等待或虚构未选分支的结果。
- 普通任务可直接连接多个执行前驱，默认按 all 等待本次全部有效前驱并接收其结果，无需额外插入汇合节点；输入线不参与等待。
- 原始用户输入默认不注入任务，需要用户显式连接。
- 输入来源必须在目标执行路径上保证可用；缺失报错，不静默省略、不隐式等待或补执行。
- 串行回环复用回环外已完成结果，返回时交接刚结束的审查意见；回环内的实现结果绑定本轮。
- 图在启动时固定。模板/路由是否进一步固定仍未确定；不能自动扩大冻结范围。
- 界面用统一拖线入口，点击连线选择执行或输入；实线、虚线及方向箭头明确展示类型。

### 四组模型配置对照

| 配置 | 需要回答的问题 |
| --- | --- |
| 单 Agent＋强模型 | 基础交付能力与成本是多少？ |
| 单 Agent＋低成本模型 | 仅替换为低成本模型能达到什么效果？ |
| 多 Agent＋全部强模型 | 流程分工本身带来多少收益与额外开销？ |
| 多 Agent＋混合模型 | 分节点模型配置能否在保持质量的同时降低总成本？ |

- [ ] 四组使用相同任务、代码初始版本、工具能力、可获得的原始材料和权限，并共用预先固定的独立验收标准；任务专属答案与隐藏测试不进入 Agent 输入，需要人工评分时尽量隐藏配置身份。
- [ ] 预先固定并记录角色、图、任务指令、模型版本、采样参数、返工上限、人工帮助规则、总预算上限与端到端超时；多 Agent 两组使用同一工作流，仅改变模型分配。
- [ ] 预算按整个工作流计量，纳入所有节点、失败、审查和重试；分别记录模型费用、执行环境开销和人工投入，不能只比较成功路径的单次调用。
- [ ] 为关键配置安排多次独立运行，记录成功率波动、样本量和不确定性；公开结果保留完整失败样本及排除理由。
- [ ] 先验证“相近成功率下节省多少成本”和“同一预算上限下多完成多少任务”，再扩展任务规模；对小样本结果保留探索性结论。

### 统一指标与交付物

| 指标 | 口径 |
| --- | --- |
| 任务成功率 | 由预先固定的独立验收判定；包括问题解决与既有功能回归 |
| 总费用 | 全部尝试的实际模型费用，包含失败、返工、重试及计费差异 |
| 成功任务均摊费用 | 全部尝试的模型总费用 ÷ 成功任务数；零成功时标为不可计算，不写成 0 |
| 总耗时 | 从任务启动到所属工作结束的端到端耗时，包含排队、审查与返工；人工等待另列 |
| 人工接管 | 次数、原因及投入时间；固定哪些帮助允许、帮助后是否仍算自主成功 |
| 控制规则违规 | 越权、输入缺失或泄漏、错误轮次交接、重复执行及终态后工作等次数 |

- [ ] 产出可复跑的测试集清单、配置版本、原始轨迹、独立评分结果、分节点成本明细和质量—成本对照报告。
- [ ] 专属控制集的确定性规则全部通过；真实任务的质量与成本按预先声明的目标评估，不由运行后临时选定的阈值宣布成功。

验收：第三方能从相同任务和配置复跑结果，区分流程正确性、任务交付质量及成本收益；本项不得因原有单元测试或单次公开基准通过就勾选完成。

## 必须通过的业务验收案例

| 案例 | 必须观察到的结果 |
| --- | --- |
| 开始执行与用户请求 | 只有启动执行关系时不独立注入原始请求；显式用户输入关系才提供请求；只有输入关系不能启动任务 |
| 执行自带交接 | A → B 时 B 收到 A 本次结果；不要求再画 A ⇢ B |
| 非传递式上下文 | A → B → C 时 C 不自动收到 A；显式 A ⇢ C 才引用 A |
| 设计与实现审查 | 实现 → Review 交接本轮实现，设计 ⇢ Review 提供设计文档，Review 无额外原始用户输入 |
| 多前驱直接汇入 | A、B 直接连接 C，无需额外 all；任一有效前驱未完成时 C 不执行，全部完成后执行一次并取得全部结果 |
| 显式 all | 与任务直接汇入使用相同的有效分支等待和结果合并规则 |
| 条件分支 | 只走一条选中的执行路线；all 不等待或使用未选分支结果 |
| 不可用输入 | 保存时拒绝可识别错误；运行时缺失在目标执行前失败，不等待、不省略、不补跑 |
| 串行返工 | 设计一次；首轮实现没有返工意见；下一轮接收上一轮审查意见并复用设计；Review 读取本轮实现 |
| 两类图关系 | 添加输入线不产生执行激活，也不被误判为控制回边；真正返工由条件执行边表达 |
| 编辑与持久化 | 连线类型切换后可见、可选、可保存重开；有环与非法草稿均不冻结画布 |
